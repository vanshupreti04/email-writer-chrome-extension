# 🔌 Email Reply AI – Chrome Extension

A Chrome Extension that integrates directly with Gmail to generate AI-powered email replies using Google Gemini API via a Spring Boot backend.

# 📥 Installation (Local Setup)

---

## 🟦 Step 1: Download Repository
➡️ Clone or download this repository from GitHub.


## 🟦 Step 2: Open Chrome Extensions Page
➡️ Go to the following URL in Chrome:

👉 chrome://extensions/


## 🟦 Step 3: Enable Developer Mode
➡️ Toggle ON **Developer Mode** (top-right corner)


## 🟦 Step 4: Load Extension
➡️ Click on the button:

🟩 **Load Unpacked**


## 🟦 Step 5: Select Folder
➡️ Choose the extracted extension folder


## 🎉 Done!

✔ Extension is now installed  
✔ Ready to use inside Gmail  
✔ AI reply button will appear automatically
